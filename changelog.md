## Version 1.01

- Assets files are now a seperate download from the main one (GameBanana only).

- All the required and conflicting codes are consolidated into a single window, rather than being presented individually.

- Edited Jumpball CEMTs and Fixed Spin Dash Glow Outline are now part of each character's directory.

- Added 0. Unmodified folder to the Add-Ons folder if you wish to revert these changes.

- Fixed the loud Grand Slam sound.

- Fixed Tails' tail spin sounds playing inconsistently.

- Fixed looping sounds not ending properly when they should (i.g. Power Boost, rolling, etc.).

- Fixed jump auto-curl while underwater.

- Fixed jump_s_loop pupil animations.

- Fixed Sonic being able to Jump Dash twice from standard and double jump.

- Sonic can now Jump Dash once out of aerial parry.

- Fixed Amy being able to Homing Attack in Cyber Space while Hammer Combat is enabled, where it is disabled by default.

- Fixed Tails, Knuckles and Amy being able to do Air Trick Finishers.

- Fixed Tails' Tail Swipe not cancelling when interrupted (i.g. suddenly jumping or interacting with a spring).

- Sonic's Spin Dash can now be properly unlocked via the Skill Tree.

- Added compatibility with Always Unlocked Spin Dash, Rail Crouch and Homing Attack Trick Animations.

- Added Air Tricks animations for Super Sonic, mainly for use with the Homing Attack Trick Animations code.

- Allow Boost to Damage Objects code is now part of the required codes.

- Added an option that disables Tails' tail spin sounds while running.

- Added an option that disables the boost aura trail.

- Added an option that makes Super Sonic lose 20 rings upon damage.

- Knuckles' digging ability is now optional.

- Knuckles has a short window until he can dig from Heat Stomp land.

- Super Sonic's damage animation plays when getting hit by The End's energy ball projectiles in Another Story.

- Added a damage start and critical recovery animations for Super Sonic.

- Sonic's Cyber Corruption running cycle is now a permanent feature.
